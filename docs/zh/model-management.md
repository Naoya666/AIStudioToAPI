# 模型管理

管理员登录后从侧栏进入“模型管理”（`/models`）。模型目录、四档账号权限、预估每日次数与 Token、抗截断策略均在此维护。

## 添加与调整

1. 点击“添加模型”，填写真实上游模型 ID。Playground 直接填写 ID，Build 使用 `build/模型ID`。
2. 新模型默认启用，继承全部通用功能。按需勾选 Free、Pro、Ultra 5x、Ultra 20x 账号权限；功能开放与账号授权分别管理。
3. 在详情抽屉编辑显示名称、描述、输入输出 Token 上限、生成方法、功能开关和各层级预估额度。
4. 点击“保存全部修改”。目录登记、权限、额度和功能策略原子保存并热应用，无需重启或发布新版本。移除模型时同时清除其层级授权，历史用量保留。

功能配置未覆盖时默认为允许。管理员可关闭协议、函数工具、内置工具组合、结构化输出、多模态、流式、思考参数、抗截断及其组合准入。上游失败不会自动修改管理员策略；恢复通用功能会清除该模型的功能覆盖。

功能开关控制项目已有处理链路的准入，不创建新适配器。Build 目前仅实现 OpenAI Chat，抗截断目前使用 OpenAI Chat 处理链路；全局 Build 与抗截断开关仍然生效。新模型可以直接进入这些通用链路，不再依赖模型名称代码白名单。

## 主动探测与分页

点击“主动探测上游模型”，使用一个现有账号页面的登录态重新请求 AI Studio `ListModels`。需要先启动并登录账号；该目录反映本次所选账号可见的模型，其他账号或层级可能不同。请求超时、登录态失效或协议异常时显示错误，不修改本地目录。

结果按新模型、元数据变化和已存在分类，并展示本地独有模型。带 `code_assistant` 能力的模型同时提供 `build/` 候选项。可筛选结果、跨页勾选或全选新模型，点击“将选中模型加入草稿”后配置层级权限，再“保存全部修改”。探测及导入均保留已有草稿；已有模型的配置不会被覆盖，上游未返回的本地模型不会自动删除。重新探测会清空上次勾选。

本地目录支持每页 15、30、50、100 条和页码跳转；搜索、筛选或修改每页条数时回到第一页，删除导致页数减少时自动回到有效页。批量操作仍作用于整个筛选结果。

## 额度与草稿

额度中的空值为未知，`0` 为已知额度为零；次数和 Token 独立覆盖。来源、覆盖更新时间、重置规则备注一并保存。预估用于展示，实际限流继续依据上游响应；重置备注不改变现有太平洋时间日窗口。

批量启用、禁用和授权只作用于当前搜索与筛选结果；复制层级权限作用于整个目录。所有修改统一保留为草稿，提供变更摘要和离页提醒。版本冲突返回 409 并保留草稿，不覆盖其他页面已保存的配置。

## 数据与接口

初始目录来自 `configs/models.json`，已有权限和额度初值沿用原有规则。首次在模型管理页保存后，完整目录作为 `MODEL_CATALOG` 写入 `data/managed-config.json`；此后启动、恢复和请求准入使用已保存目录。原文件仅作为未配置目录时的种子，可由管理员主动探测上游目录，不会自动加入模型。

- `GET /api/model-catalog`：读取目录、权限、初始额度、全局抗截断设置和配置版本。
- `POST /api/model-catalog/discover`：主动请求上游目录，返回账号、探测时间、模型对照及本地独有条目，不写入配置。
- `PATCH /api/model-catalog`：提交 `version`、`rows`、`permissions`、`antiEnabled` 和 `antiDefault`。

上述接口均使用现有管理登录认证。保存复用配置服务的字段校验、版本检查、原子写入及失败回滚。概览页原有启用／禁用入口在配置了管理目录后同步写入同一目录。
